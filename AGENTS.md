# SimpleSEO Agent Instructions

SimpleSEO is a universal SEO, Sitelinks, Schema.org, Core Web Vitals, and AI Search (GEO) skill pack built to work with any AI coding agent (Oh My Pi, OpenAI Codex, Claude Code, Cursor, Gemini CLI, OpenCode, Windsurf, or Cline).

When a user invokes `/simpleseo`, `/SimpleSEO`, or asks to run **SimpleSEO**:

1. Read `SKILL.md` from the repository root first.
2. Always run **Gate 1 (Prerequisite Check)** and wait for the user's answer before touching any code or submitting to search engines.
3. If prerequisites are missing, follow `references/prerequisite-setup-guide.md` and stop.
4. Once prerequisites are confirmed, run **Gate 2 (Sub-Skill & Benefit Breakdown + Execution Confirmation)** and wait for explicit approval.
5. After approval, execute the phases in `SKILL.md` using the modules in `subskills/` and the standalone Python 3 scripts in `scripts/`.
6. Never insert em-dashes (`\u2014`), fabricated statistics, fake reviews, or non-standard `robots.txt` directives.
